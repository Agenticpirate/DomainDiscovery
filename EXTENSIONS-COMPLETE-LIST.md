## Features:

✅ **205 domain extensions** across 16 categories
✅ **Real-time availability checking** via Instant Domain Search MCP API
✅ **Batch processing** - checks 50 domains at a time
✅ **Debounced search** - 500ms delay to prevent excessive API calls
✅ **Glowing status indicators** - green (available), red (taken), white (checking)
✅ **Affiliate-protected** - text selection disabled on domain names
✅ **Direct registration** - click available domains to register via GoDaddy
✅ **Category filtering** - filter by any of the 16 categories
✅ **Compact, minimalistic design** - matches your website style
✅ **Responsive grid** - adapts from 2 to 6 columns based on screen size

## Data Source:

Extensions are stored in: `src/data/extensions.json`

This allows for easy updates and maintenance without modifying the component code.

## How It Works:

1. User types a keyword (e.g., "startup")
2. System builds domain list: startup.com, startup.net, startup.io, etc.
3. Checks availability in batches of 50
4. Updates UI in real-time as results come in
5. Shows glowing status dots for each extension
6. Click available domains to register via GoDaddy
